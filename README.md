# Red de Intercambio - Universidad Central 🎓

Este es un proyecto de aplicación móvil desarrollado con [Expo](https://expo.dev) y creado con [`create-expo-app`](https://www.npmjs.com/package/create-expo-app), diseñado exclusivamente para que la comunidad de la Universidad Central pueda intercambiar productos coleccionables de forma segura y directa.

## Características principales

- **Registro de usuarios:** Creación de perfil exclusivo para estudiantes y miembros de la universidad.
- **Gestión de coleccionables:** Publica, registra y ofrece los productos coleccionables que deseas intercambiar.
- **Sistema de intercambio:** Explora publicaciones de otros usuarios y concreta trueques dentro de la comunidad universitaria.
- **Chat integrado:** Comunícate en tiempo real con otros coleccionistas para coordinar los detalles de los intercambios.
